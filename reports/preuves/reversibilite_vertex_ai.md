# Documentation officielle consultée le 5 novembre 2026

Source demandée : https://cloud.google.com/vertex-ai/docs/export/export-model-tabular

Page servie : https://docs.cloud.google.com/gemini-enterprise-agent-platform/machine-learning/export/export-model-tabular

L'export des modèles AutoML tabulaires de classification et de régression est documenté, avec le format d'export tf-saved-model et un serveur Docker à télécharger. L'export de prévision n'est pas pris en charge. Les prédictions exportées requièrent un CPU x86 avec AVX, et le service Explainable AI n'est pas disponible pour ces modèles exportés. L'export est donc une possibilité de portabilité assortie de limites, et non une garantie d'indépendance complète. Documentation lue seulement ; aucune commande cloud ni export effectué dans ce TP.
